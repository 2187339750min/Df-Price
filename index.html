API Key（必填）
在 delta-test.shallow.ink 注册 → 进入 API Key 申请页面 → 创建一枚 Key 粘贴到这里。
Key 只保存在本机浏览器（localStorage），不会上传到任何地方。
数据源地址
默认用「新版接口」（就是你在 delta-test.shallow.ink 注册的那个站对应的后端）。
如果你拿的是老插件那种 Key，就换成「旧版插件接口」。自检不过时挨个试。
