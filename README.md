# 三角洲行动 · 物价雷达

一个**纯网页版**的三角洲交易行物价查询工具。手机上打开就是 App，可「添加到主屏幕」，不需要电脑、不需要服务器、不需要装任何东西。

> 已实测跑通：用真实 API Key 验证过全部功能，取到真实价格、真实利润排行和真实历史曲线。

---

## 一、它能做什么

| 功能 | 说明 |
|---|---|
| 实时物价 | 搜索物品 → 当前均价、近 24 小时涨跌幅 |
| 价格走势图 | 小时级历史价格曲线，标出最高/最低点 |
| 自选行情板 | 常关注的物品一屏看完价格 + 迷你走势 + 涨跌 |
| 子弹利润排行 | 特勤处造弹药的利润榜：时均利润 / 总利润 / 日环比排序，按口径筛选 |
| 利润历史曲线 | 点利润卡片看该子弹的利润走势，可切「时均 / 总利润」双口径，带配方材料 |
| 价格提醒 | 设上限/下限，价格触及时弹通知 + 震动 |
| 离线可看 | 数据存在手机本地，没网也能看上次的行情 |
| 导出导入 | 自选列表导出成文本，换手机粘贴过去 |

## 二、数据从哪来（先看这段，能省你很多时间）

三角洲官方**没有**开放交易行接口。本工具用的是社区维护的第三方服务（浅巷墨黎团队），它其实有**两套后端**：

| 后端 | 地址 | 认证方式 | 说明 |
|---|---|---|---|
| ✅ **新版**（默认） | `delta-test-api.shallow.ink/api/v1` | `X-API-Key` | 就是你注册的 `delta-test.shallow.ink` 网站对应的后端，**当前主力** |
| 旧版 | `df-api.shallow.ink` | `Authorization: Bearer` | 老插件（云崽/NoneBot 等）用的那套 |

**本工具默认用新版，并且两套都做了兼容**（请求同时带两种认证头、路径也做了双路回退），所以换哪个后端都能跑。

你在设置里可以随时切换。

## 三、第一步：申请 API Key

注册完成后，创建 Key 的页面是固定的这一页：

### 👉 https://delta-test.shallow.ink/developer/api-keys

1. 手机浏览器打开（**要先登录**，没登录会被弹回登录页）
2. 页面上点 **创建 / 新建 API Key**
3. 复制那串 `sk-xxxxxxxx`
4. 回到物价雷达 →「设置」→ 粘到 **API Key** →「保存设置」→ 点「连通性自检」

**找不到入口的备用路径**：在 `https://delta-test.shallow.ink/` 登录后，点**右上角头像**找「API 密钥 / 开发者」；或地址栏手动把域名后改成 `/developer/api-keys`。

> 站点上的「用户 ID」不用管——那是给别的机器人插件用的（叫 `clientId`），本工具只用 Key。

## 四、第二步：部署（手机就能做完）

只需要 **2 个文件**：`index.html` 和 `manifest.webmanifest`。

> `worker.js` **不用了**。我实测过新版后端完整支持跨域（返回 `Access-Control-Allow-Origin: *`，预检也放行 `X-API-Key`），浏览器可以直接访问，不需要中转。

### 用 GitHub Pages（免费、全程手机可操作）

1. 手机浏览器打开 `github.com`，登录（没有就注册）
2. 右上角 `+` → **New repository**
   - Repository name 填 `df-price`
   - 选 **Public**
   - **Create repository**
3. 进入仓库 → **Add file** → **Create new file**
   - 文件名填 `index.html`
   - 把 `index.html` 的**全部内容**粘进去 → 拉到底 **Commit changes**
4. 再做一次，建立 `manifest.webmanifest`，粘贴同名文件内容
5. 仓库 → **Settings** → 左侧 **Pages**
   - Source 选 `Deploy from a branch`
   - Branch 选 `main`，目录选 `/ (root)` → **Save**
6. 等 1～2 分钟刷新，顶部出现你的网址：`https://你的用户名.github.io/df-price/`

**这个网址就是你的 App。**

> 💡 在电脑上把这两个文件拖拽上传到仓库更省事；但没有电脑也完全可行。

---

## 五、第三步：填入 Key

打开你的网址 → 底部「**设置**」→

| 项 | 填什么 |
|---|---|
| API Key | 你申请到的那串 `sk-...` |
| 数据源地址 | 保持默认「新版接口 /api/v1」 |
| 自动刷新 | 建议开，间隔 5 分钟 |

点 **保存设置** → 点 **连通性自检**，看到 ✅ 就成了。

### 🔒 关于 Key 的安全（重要）

**Key 只存在你手机浏览器的 localStorage 里**，`index.html` 里不包含任何密钥——所以这个网页可以放心公开。我在交付前专门校验过文件里没有硬编码 Key。

不要为了图省事把 Key 写进 `index.html` 再传到公开仓库，那样任何人都能用你的额度。

## 七、怎么用

1. **行情**：自选物品的价格、涨跌、迷你走势；点卡片看小时级价格曲线、设提醒阈值
2. **搜索**：输物品名（如 `金条`）或点快捷标签 → 结果里点 **+ 自选**
3. **利润**：子弹制造利润排行
   - 右上角按钮循环切换 **时均利润 → 总利润 → 日环比**
   - 名称下方是**口径筛选**标签（5.56x45 / 7.62x39 / .45 ACP…）
   - **点卡片**进入利润详情：利润走势曲线 + 双口径切换 + 平均/最高/最低 + 配方材料 + 制造场所/周期/产量
   - 右下角 **+ 自选** 把它加进行情板盯价格

**刷新策略**：页面打开时按设定间隔自动拉；切回前台立刻刷新。现价每次刷新都拉，历史曲线 30 分钟才拉一次（省额度）。

**利润口径说明**：官方接口每条记录同时给 `hourProfit`（折算到每小时）和 `totalProfit`（单次制造）。
制造周期长的子弹单次利润看着高，但时均可能不如周期短的——所以**横向比较用时均，看单次到手用总利润**。

## 八、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 自检报 401 | Key 不对或过期，重新去 `/developer/api-keys` 复制；也可能数据源地址要换成「旧版插件接口」 |
| 自检报 400 | 一般不用管，说明认证已经通过了 |
| 网络请求失败 | 检查手机网络；或换个数据源地址 |
| 提示「请求过于频繁」 | 把自动刷新间隔调大 |
| 价格偏旧 | 上游是社区采集的快照，不是官方实时流，以游戏内为准 |
| 利润页没数据 | 该时段上游还没生成弹药制造数据；过会儿点右上角刷新 |
| 利润曲线「暂无历史数据」 | 该物品暂时没有历史采样点 |
| 提醒不弹 | 网页无法后台常驻，**页面得活着才会检查阈值**。iPhone 上 Safari 网页不支持系统通知，只有页内提示 + 震动；Android / 桌面 Chrome 可弹系统通知 |
| 换手机后自选没了 | 设置 → 导出 → 新手机导入 |
| 想清空重来 | 设置 → 清空自选；或清掉该站点浏览器数据 |

## 十、技术说明

- **零依赖**：不引入任何框架/图表库/CDN
- **一套图表引擎**：价格曲线和利润曲线共用 `renderLineChart()`，手写 SVG 路径 + 网格 + 极值标注；SVG 属性用**字面色值**而非 `var(--x)`，避免部分浏览器不解析 CSS 变量导致线画不出来
- **双后端兼容**：认证同时发 `X-API-Key` 和 `Authorization: Bearer`；接口路径用「404 即回退」策略自动切换；参数名同时发两套（如 `objectName`+`name`）
- **多格式容错解析**：兼容 `data.list` / `data.prices` / `data.items` / `data.keywords` / `data.groups` / `data.manufacturingPlaces` 等所有已知结构，以及秒级/毫秒级时间戳、ISO 字符串
- **子弹识别三重兜底**：弹药字典（权威，113 条）→ ID 段（两套后端不同：`371/372/373` 与 `1501`）→ 名称特征正则
- **本地缓存**：`localStorage` 存自选、阈值、配置、历史曲线、弹药字典；历史点自动裁剪到最近 8 天（上游一次返回 4000+ 点，会被裁到约 192 点）
- **内置自检**：一键分别测试直连和代理，直接告诉你哪条路通

### 用到的接口

| 用途 | 新版（/api/v1） | 旧版 |
|---|---|---|
| 搜索物品 | `GET /df/object/search?objectName=` | `?name=` |
| 批量取价 | `GET /df/object/search?objectID=a,b` | `GET /df/object/price/latest?id=[...]` |
| 价格历史 | `GET /df/object/price/ams/history/v2?objectId=` | `GET /df/object/price/history/v2?objectId=` |
| 弹药字典 | `GET /df/object/ammo?days=1` | 同 |
| 制造利润 | `GET /df/place/profit` | `GET /df/place/profitRank/v2?type=hour` |
| 利润历史 | `GET /df/place/profit/history?objectID=` | `GET /df/place/profitHistory?objectId=` |

认证：新版 `X-API-Key: <Key>`；旧版 `Authorization: Bearer <Key>`。
